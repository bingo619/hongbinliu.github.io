ReSkitch Support

How do I take my first screenshot?

Choose Screen Snap, Window Snap, or Full Screen from the menu bar icon. For a region, drag around the area, adjust the corners if needed, and press Return. For a window, hover over a window in another app and click to capture it. Esc cancels.

How do I enable screen access?

Start a capture to trigger the macOS permission prompt. In System Settings, open Privacy & Security and find Screen Recording or Screen & System Audio Recording. Enable ReSkitch, then reopen it if macOS asks. To annotate an image you already have, drag it into ReSkitch or use File → Open.

How do I change the capture shortcuts?

Open ReSkitch → Settings with ⌘,, select the shortcut for a capture mode, press a new key combination, then save. If ⇧⌘5 opens the macOS Screenshot app, choose another combination in ReSkitch or change the system binding in System Settings → Keyboard → Keyboard Shortcuts → Screenshots.

How do I edit or share an annotation?

Drag an existing annotation to move it. Double-click text to edit its wording. Use Save to ReSkitch to keep an editable project. To send a flattened image, choose File → Export Image or drag the handle at the bottom into Finder or an app that accepts images or files. Click the extension next to the filename to choose PNG, JPEG, or TIFF.

An editable project includes the original pixels under blur and pixelation. Share a flattened export when you want the recipient to see only the edited result.
